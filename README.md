# Good Vision Home Health Care — Website

A responsive React + TypeScript + Vite website using the supplied Good Vision palette.

## Requirements
- Node.js 20 or newer
- npm

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
npm run preview
```

## Included routes
- `/` — Home
- `/about` — About
- `/services` — Services overview
- `/baby-newborn-care` — Baby & newborn care
- `/home-healthcare` — Home healthcare
- `/nursing-services` — Nursing services
- `/how-it-works` — How it works
- `/locations` — Nellore, Vijayawada and Eluru
- `/faqs` — FAQs
- `/contact` — Contact and enquiry
- `/book-a-visit` — Enquiry entry point
